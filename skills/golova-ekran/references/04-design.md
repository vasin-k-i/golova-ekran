# Инфографика, вставки, обложка

## Панели (раскладка D)

Панель встаёт на место экрана. Пункты **проявляются по одному** — иначе на семьдесят
секунд в кадре стоит статичная картинка.

```python
PANELS = {
    "hook": dict(eyebrow="ЛОКАЛЬНО · БЕЗ ПОДПИСОК · 0 ₽",
                 w1="Монтаж", w2="без монтажёра",     # w2 — акцентным цветом
                 items=["режет тишину и паузы",
                        "убирает оговорки и дубли"],
                 note="мелкая сноска внизу"),
    "final": dict(eyebrow="ЗАБИРАЙ", w1="Гайд", w2="по ссылке",
                  bullets=["Ссылка в описании"], cta="Открыть ↓"),
}
```

`items` — нумерованный список с проявлением, `bullets` — точки без проявления и с кнопкой.

Строки держи короче 46 символов, иначе не влезают. Кегль считается от высоты панели.

⚠️ **В Arial нет знака рубля** (U+20BD) — вместо ₽ рисуется пустой прямоугольник.
Скилл сам подставляет запасной шрифт под такие символы. Проверить, что запасной нашёлся:
`montage.py check`.

⚠️ **Проверять наличие глифа через `getmask().getbbox()` бесполезно** — у отсутствующего
символа bbox тоже непустой. Сравнивать растр с растром заведомо пустого кодпоинта.

## Вставки

Окно в экранной зоне с подписью сверху: показать кусок другого своего видео, не разбирая
основной кадр. **Звук источника не берём никогда** — говорит по-прежнему автор.

```python
INSERTS = [dict(n="01", take="01", at=44.0, dur=4.5, lay="A",
                src="/путь/клип.mp4", ss=296.0, speed=1,
                crop="crop=1521:856:292:49",      # необязательно
                blur=[(128, 194, 164, 32)],       # замазать имена/лица
                label="ЧТО ПОЛУЧАЕТСЯ")]
```

- `at` — якорь в исходнике дубля, `dur` — сколько висит в готовом.
- `speed=8` ускоряет источник в 8 раз: длинный скринкаст показывают бегло.
- Вставка обязана целиком помещаться в блок своей раскладки, иначе `build` остановится
  и скажет, какую именно подвинуть.
- ⚠️ `boxblur` требует радиус меньше половины меньшей стороны области — на узких полосках
  (таблички с именами высотой 32 px) с большим радиусом он падает.

Кегль подбирается под колонку сам, но три-четыре слова в строке уже не влезут.

Проверяй читаемость по `work/cover_preview.png` (480×270): если в превью заголовок
