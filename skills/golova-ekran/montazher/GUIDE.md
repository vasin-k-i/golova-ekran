# Монтажёр — гайдлайн монтажа длинного YouTube-ролика

«Монтажёр» — вариация скилла golova-ekran. Чистый мастер (паузы, повторы и оговорки
вырезаны) он превращает в ролик, который смотрится как работа живого монтажёра:
человек во весь кадр, вставки на каждом смысловом шаге, текст прямо по видео, хук из
ударных фраз и полноэкранная отбивка.

Стиль собран на ролике «Арбитраж: входной билет в любой бизнес» (17 минут, 100 планов,
99 текстов). Эталоны — работа живого монтажёра на канале автора и разбор чужих роликов
с сильным началом. Всё, что ниже записано как правило, отсмотрено и утверждено, а
забракованное отмечено как запрет.

## Когда брать Монтажёр, а когда студию golova-ekran

| | Студия golova-ekran | Монтажёр |
|---|---|---|
| Материал | голова + запись экрана одним дублем | голова + сколько угодно вставок со стороны |
| Основа кадра | раскладки: голова в карточке, экран окном | человек во весь кадр, вставки поверх и вместо |
| Ролик | урок, разбор кабинета, «смотрим на экран» | разговорный YouTube, личный бренд, кейсы |
| Хук | нет | 6–10 ударных фраз с переходами-кругами |

Мастер в обоих случаях один и тот же: тишина режется по амплитуде, повторы ищутся
посегментной расшифровкой и согласуются до резки. Монтажёр начинается после
`montage.py cut`.

## Порядок работы

```
# 1. мастер — основной пайплайн, как обычно
montage.py probe --pair ГОЛОВА …    # или руками project.py, если экрана нет
montage.py segments && montage.py transcribe && montage.py repeats
montage.py repeats --approve "кто согласовал"
montage.py plan && montage.py cut

# 2. монтаж — Монтажёр
montazher.py init         # montazher.py + edl.py + шрифт Montserrat
montazher.py words        # пословные таймкоды → края вставок по словам
montazher.py audio        # звук мастера, цель −14 LUFS
# … собираешь вставки, пишешь edl.py …
montazher.py check        # покрытие, повторы, файлы, ритм, текст
montazher.py texts        # текст по видео (HyperFrames)
montazher.py render probe # 1–2 минуты на утверждение стиля
montazher.py render all
montazher.py hook         # хук и отбивка
montazher.py final        # хук → отбивка → ролик
montazher.py sheet        # контактный лист готового ролика
```

Монтажный лист `edl.py` пишется в секундах исходника. В время готового ролика их
переводит `s2o()`, поэтому перерезка пауз лист не ломает. Края вставок ставь по словам:
`W("03", "накрутка")` — секунда, где начинается это слово.

## Кадр

**Основа — человек во весь кадр, 55–60 % времени.** В примере: FULL 58 %, SPLIT 13 %,
PIP 11 %, CARD 10 %, BROLL 9 %.

| Тип | Что в кадре | Когда |
|---|---|---|
| `FULL z=1.0` / `z=1.25` | человек во весь кадр, общий или крупный | основа; крупность меняется на смене мысли |
| `PIP` | экран во весь кадр, человек окошком в правом нижнем углу | показываешь сайт, кабинет, цифры |
| `SPLIT` | экран окном слева, человек справа | экран и человек одинаково важны |
| `CARD` | документ высокой скруглённой карточкой сбоку, с прокруткой | гайд, кейс, переписка, пост |
| `CARD behind=True` | та же карточка ЗА человеком (маска) | самый «дорогой» вид, для ключевых документов |
| `BROLL` | вставка во весь кадр, голос идёт дальше | живой кадр работы, ИИ-иллюстрация |

- **Вставка на каждом смысловом шаге, 3–6 с.** Назвал сайт — показал сайт. Сказал «вот
  мне пишут» — показал переписку. Короче 0,6 с вставка не читается: `check` предупредит.
- **Крупность головы меняется решительно и редко:** 1,0 ↔ 1,25 на смене мысли, не чаще
  4 раз в минуту. Цифровой зум на каждой склейке запрещён — читается как дёрганая камера.
- **Каждый кусок каждого клипа — один раз.** Повтор вставки зритель замечает сразу.
  `check` ищет повторы по исходнику и времени и не пускает лист с повтором.
- **Что брать во вставки, по убыванию ценности:**
  1. запись своей реальной работы: скринкаст сайта, кабинета, канала, переписки;
  2. живой кадр, доснятый на телефон (руки за ноутбуком, стол, процесс);
  3. ИИ-би-ролл — только там, где первых двух нет.

### ИИ-би-роллы

- Сначала **картинки на утверждение**, потом оживление. Без утверждения не генерировать видео.
- Только фотореализм, документальная съёмка. «Пластик» забракован: глянцевые лица,
  идеальный свет, мультяшность.
- По возможности — из референсов автора: его кабинет, его фото, его модель лица.
- Рецепт, который прошёл: картинка GPT Image 2.5 high 2k (Higgsfield, 2,75 кредита) →
  Kling 3.0 image-to-video 5 с (10 кредитов, 720p) → апскейл до 1080p. Nano Banana на
  этих сюжетах дал «пластик».
- Ни одного повтора, даже другим отрезком того же клипа в соседней главе.

## Текст по видео

- **Шрифт — Montserrat.** Строка подводки — курсив 400, под ней капс 800 с акцентным
  словом (`*слово*` в листе = цвет акцента). Никаких плашек, карточек и «презентации»
  под текстом — только мягкое затемнение края кадра.
- **Позиции:** `wall` — слева у стены рядом с головой (рабочая); `low` — нижняя треть;
  `title` — заголовок главы с надстрочником; `win` — окошки инфографики рядом с головой.
- **Инфографику — окошками рядом с человеком, не на весь экран.** Полноэкранная доска
  с цифрами была забракована: «лучше в плашку рядом со мной».
- Одна мысль — один текст. Кегль подбирается по реальной ширине строки, текст не
  вылезает из рамки; сильно ужатое `check` покажет — сократи формулировку.
- Счётчик (`COUNT:`) — для одной главной цифры ролика; пункты (`LIST:`, `WIN:`)
  появляются по слову.
- **Цифры на экране — только сказанные вслух или видимые в кадре.** Оговорился в цифре —
  на плашке правильная, а оговорку лучше вырезать.

## Хук и начало

Утверждено с первого показа («СУПЕР»), менять без причины не стоит.

- **6–10 ударных фраз встык, 15–20 с.** В каждой — одна цифра или резкое обещание из
  самого ролика. Звук без пауз (зазор 0,03 с), картинка уходящей фразы держится ещё 0,55 с.
- **Переход — круг, растущий из лица** со следующей фразой: с ускорением, центр уезжает
  к середине кадра, тонкий светлый ободок. На первой фразе — удар-отъезд 1,3 → 1,0.
- **Текст хука:** подводка тонким курсивом, слова всплывают из размытия; ключ —
  сверхжирный курсив с градиентом красный → оранжевый → жёлтый и свечением, печатается
  маской по буквам.
- **Музыка-подложка** (ElevenLabs Music, 20 с), −16 дБ, проседает под голос, в конце
  обрыв и 0,2 с тишины.
- **Отбивка 1,4 с:** полноэкранная заливка шторкой с именем и темой, свист и низкий удар.
- **Границы каждой фразы проверяй расшифровкой клипа.** Пословные таймкоды whisper
  сдвинуты на 0,1–0,3 с: фраза начинается с хвоста предыдущего слова или съедает своё
  первое. Первая версия хука была с паузами между фразами — забраковано: «слишком большие
  паузы».

## Звук

- Цепочка мастера: highpass 75 Гц → компрессор 2,5:1 → +19 дБ → лимитер 0,84. На
  телефонной записи даёт −14,1 LUFS. `audio` печатает итог.
- Хук собирается громче мастера — сводится к тем же −14 (`gain_db`, по умолчанию −3,5 дБ).
- Звук вставок не берём: голос идёт поверх.

## Приватность

- Личные суммы, доходы, балансы — не в кадр. Кусок скринкаста с ними пропускаем,
  а не замазываем.
- Переписка — только с согласия; чужие имена, лица, телефоны — размыть или не брать.
- Имена партнёров и клиентов в тексте ролика не называем без их согласия.
- При записи скринкастов браузером-роботом блокируй счётчики аналитики, иначе запись
  накрутит визиты собственным сайтам.

## Проверка перед показом

1. `check` — ошибок ноль: план встык от 0 до конца, ни одного повтора, все файлы на месте.
2. `render probe` на 1–2 минутах — стиль утверждён человеком до полного рендера.
3. Расшифруй каждый стык мастера ±1,5 с отдельным клипом: каждая вырезанная оговорка
   звучит один раз, обрывков слов нет. На всей дорожке whisper обрывки склеивает.
4. Громкость готового ролика −14 ± 1 LUFS.
5. `sheet` — контактный лист: текст в рамках, ничего не наехало на лицо, вставки там,
   где о них говорят.
6. Кадры для проверки бери точным номером (`select=eq(n\,N)`). `-ss` перед `-i`
   промахивается до ключевого кадра, и на кадре будет не то, что в ролике.

## Грабли

- HyperFrames: класс `.hero` из общих стилей уже абсолютный — свои классы называй иначе.
- `background-clip:text` с градиентом не уважает прозрачность детей: печатать градиентный
  текст по буквам — только маской `clip-path` шагами.
- Многопоточный захват HyperFrames при нехватке памяти падает — `GEK_HF_WORKERS=1`
  (Монтажёр ставит по умолчанию).
- Маска «за человеком» — `npx hyperframes remove-background`, нужен node ≥ 22
  (`MZ_NODE_BIN=/путь/к/node/bin`).
- `zoompan` — единственный способ менять зум во времени: у `crop` ширина и высота не
  анимируются.

## Пример

`example/` — настоящий лист и конфиг ролика «Арбитраж» (пути к вставкам обезличены):

- `example/edl.py` — 100 планов и 99 текстов на 17 минут, с комментариями по главам;
- `example/montazher.py` — конфиг с хуком из 9 фраз;
- `example/frames/` — кадры каждого типа: хук с кругами и отбивкой, текст у стены,
  PIP, крупный план, заголовок главы, SPLIT, карточка за человеком, карточка сбоку.

Готовый ролик целиком выйдет на YouTube-канале автора под названием «Арбитраж: входной билет в любой бизнес».
