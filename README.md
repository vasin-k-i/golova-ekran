# Голова + экран — автомонтаж

Скилл для [Claude Code](https://claude.com/claude-code) и [Codex](https://developers.openai.com/codex/).
Кидаешь папку с сырыми дублями — получаешь смонтированный ролик.

Формат — обучающее видео: запись экрана и говорящая голова в кадре. Собирать это руками
в таймлайне — часы на каждый выпуск. Здесь всё делают локальные скрипты: **0 ₽, без
подписок, без облаков**, материал никуда не уходит с твоего компьютера.

```
сырьё 12:16  →  мастер 10:36
  · тишина и паузы вырезаны по амплитуде
  · оговорки и повторы найдены посегментной расшифровкой
  · телефон и экран синхронизированы по звуку, расхождение 1 мс
  · на записи экрана — наезд туда, где идёт действие
  · кадр собран, инфографика нарисована, громкость выровнена
```

## Установка

Проще всего — попросить агента. Открой Claude Code и вставь:

```
Установи скилл «голова + экран» из https://github.com/vasin-k-i/golova-ekran
Склонируй во временную папку, скопируй skills/golova-ekran в ~/.claude/skills/golova-ekran,
запусти scripts/check_deps.sh и покажи, чего не хватает. Потом напомни перезапустить агента.
```

Или одной командой в терминале:

```bash
curl -fsSL https://raw.githubusercontent.com/vasin-k-i/golova-ekran/main/install.sh | bash
```

Ставит туда, где среда найдена: `~/.claude/skills/` и/или `~/.codex/skills/`.
Нужна одна — `--claude`, `--codex` или `--dest <папка>`.

## Как пользоваться

Перезапусти агента и скажи своими словами:

```
смонтируй ролик из папки ~/Movies/урок — там телефон и запись экрана
```

Или: `убери паузы и оговорки из этого видео`, `собери урок голова + экран`,
`/golova-ekran ~/Movies/урок`.

Дальше агент ведёт сам: посмотрит файлы, синхронизирует дорожки, вырежет тишину,
расшифрует каждый сегмент, покажет список повторов **до** резки и соберёт кадр.

## Что нужно на машине

| | зачем | как поставить |
|---|---|---|
| ffmpeg | вся резка и сборка | `brew install ffmpeg` |
| python3 + pillow + numpy | графика и синхронизация | `pip3 install pillow numpy` |
| whisper.cpp | поиск повторов и оговорок | `brew install whisper-cpp` |
| модель `ggml-large-v3.bin` | к нему | [скачать](https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3.bin) |

Проверить всё разом: `bash ~/.claude/skills/golova-ekran/scripts/check_deps.sh`

Debian/Ubuntu: `sudo apt install ffmpeg fonts-dejavu python3-pil python3-numpy`.

## Что он делает по шагам

1. **Смотрит материал** — размеры, fps, поворот, есть ли звук.
2. **Синхронизирует** телефон и запись экрана кросс-корреляцией звука, в трёх точках,
   чтобы поймать разный ход часов. Хлопок не нужен.
3. **Находит окна показа с экрана.** Если ты включаешь видео на ноутбуке и показываешь
   результат, его звук приходит на микрофон тише порога тишины — обычная резка вынесет
   весь показ. Скилл ищет такие места по профилю громкости и режет их отдельным,
   тихим порогом. Это самая дорогая ошибка в жанре, и она здесь закрыта.
4. **Режет тишину** по амплитуде, не по расшифровке: модели врут про паузы.
5. **Ищет повторы и фальстарты** — расшифровывает КАЖДЫЙ сегмент отдельным клипом.
   На всей дорожке модель схлопывает фальстарт с переспросом, и повтор не виден.
   Список показывается тебе до резки.
6. **Наезжает за курсором.** Запись экрана в кадре ужимается до карточки, и мелкий шрифт
   в терминале перестаёт читаться. Скилл сам находит, где на экране идёт действие —
   по изменению картинки, а не по стрелке курсора, потому что половина работы идёт
   с клавиатуры, — и ставит туда медленный наезд. Сцену меняет только там, где
   на экране и правда сменилась вся картинка. Ничего не нужно включать во время съёмки:
   считается по готовому файлу.
7. **Собирает кадр** — четыре раскладки, блоками. Правишь один блок — пересобирается
   он один, секунды вместо минут.
8. **Рисует инфографику** — панели с проявляющимися пунктами, на месте экрана.
9. **Выравнивает громкость** до −14 LUFS под YouTube, лимитером, а не компрессором.
10. **Делает обложку** 1920×1080 с проверкой читаемости в превью.

## Одна оговорка остаётся нарочно

Если в ролике ты рассказываешь, как вырезаются оговорки, живой пример работает лучше
объяснения: ставишь номер сегмента в `BW` — кадр обесцвечивается и получает плашку
«ОГОВОРКА — ВОТ ТАК ОНА ВЫГЛЯДИТ».

## Чего он не делает

Не чистит мычания «э / эм / нуу» — нужен отдельный проход по пословному транскрипту.
Не делает клиповый монтаж с motion-графикой: это спокойный монтаж обучающего ролика.
И не решает за тебя, что резать: список повторов утверждает человек.
